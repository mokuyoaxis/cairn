# 经验检索的边界：十项负面实验记录（2026-10）

> 类型：研究记录，不是产品功能说明，也不构成路线图承诺。
>
> 时间：2026-10-28 至 2026-10-29
> 性质：合成数据、单作者标注、未接真实宿主；所有实验均未修改产品核心。
> 结论：十项实验的初始假设均未获支持。它们记录的是边界和反例，不是可直接上线的能力。

## 1. 研究问题

这组实验问的是一条经验被检索到之后的问题：

> 凭什么相信它、判断它适用、把它完整交付，并保证它在缓存和上下文变化后仍然有效？

研究对象不是“检索能不能命中”，而是命中之后的可信性、适用性和传播边界。

## 2. 实验清单

| 实验 | 研究问题 | 观察结果 |
|---|---|---|
| 阶段触发消融 | 声明的操作阶段能否替代提示时检索？ | 阶段独用精确率 6/10；按阶段过滤后的应交付覆盖 3/8，不能替代 |
| 经验过期 | 日期或依赖指纹能否证明经验失效？ | 日期只发现 1/4 失效；指纹发现 2/4，但复核量更大；复核信号不等于失效证据 |
| 相反建议冲突 | 相关度 margin 能否裁决相反建议？ | 基线仍在 4/5 冲突场景交付单边建议；前移检查降到 1/5，但损失 1/8 无冲突交付 |
| 前提快照绑定 | 新鲜快照是否仍属于当前目标？ | TTL 策略 3/4 不安全行动许可；目标/修订绑定降到 1/4，但安全许可从 5/7 降到 3/7 |
| 超时症状迁移 | 查无记录是否等于写入未发生？ | 按症状重试 4/4 产生重复；查询 absent 后降到 2/4，但未执行恢复从 4/4 降到 3/4 |
| 证据谱系 | 多条 verified 是否等于多次独立验证？ | 条目投票 5 正确 / 3 错误 / 1 unknown；按来源根去重 3 正确 / 2 错误 / 4 unknown |
| 上下文重交付 | 发过一次的卡片在压缩/编辑后是否仍可见？ | 按卡名去重 7 次内容缺失、0 次重复；按代次+修订号 3 次缺失、2 次重复 |
| 卡片截断 | 截断后的卡片是否保留适用条件？ | 默认 520 字符下可保留行动句却丢失限定条件或路径 |
| 索引新鲜度 | 写入的修改或撤回是否进入检索缓存？ | 修复前热索引 4/6、冷缓存 2/6 与重建不一致；已归档条目仍可能被缓存注入 |
| 候选预算饥饿 | 不合格候选是否会挤掉合格候选？ | 预算 8 时 20/30 丢失目标，预算 20 时 10/30；先准入再截断为 0/30 |

原始脚本和逐例输出保留在实验环境，不随本页发布；本页保留结论、口径和可核对的数据。

## 3. 共同结论

1. **相关度不是证据裁决**：margin 能排序，但不能判定两条相反建议谁更可信。
2. **准入不是撤回传播**：缓存或上下文中的旧副本可能让已归档内容继续被看到。
3. **候选截断发生在准入之前会改变结果**：不合格条目不必被注入，也能挤掉合格条目。
4. **卡片不是全文**：字符预算和名称长度都可能让限定条件或路径消失。
5. **“看过/发过”不等于“当前可见”**：去重状态、上下文压缩和交付失败是三件不同的事。
6. **单一字段扩展不足以解决这些问题**：阶段、日期、版本、来源票数都反复出现反例。

## 4. 与产品的关系

这些实验没有改变 v0.1.0 的核心行为。其中两个问题后来进入维护流程：

- 索引撤回传播：**v0.1.1 已修复**，回归测试覆盖热索引和冷缓存；
- 候选预算饥饿：作为 v0.1.2 维护项处理；修复方向是先完成契约/scope 准入，再执行候选截断。

其余实验保持研究状态，不新增字段、命令、阶段触发或自动裁决逻辑。

## 5. 边界

所有样本都是人工构造的对照，不是自然经验库抽样，也不是宿主集成测试；文中的分子/分母不能解释为真实发生率、任务收益或安全保证。实验中的 verified 元数据只是合成夹具，不代表真实环境验证。

本页支持的是“哪些结论不能由单一字段或单一排序指标推出”，不支持把这些实验直接升级为生产规则。
